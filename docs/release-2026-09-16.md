# Matrizo website release — 16 September 2026

## Scope

A navy, blue, and warm-neutral Matrizo identity across the storefront, admin portal, and employee portal. Includes responsive browsing, account creation, basket/checkout, nested categories, employee management, daily reporting, and operations review. Existing catalog data and user changes in the admin screens are retained. No production fixtures or database migrations are required. Pricing-tier reads are batched to stay within D1’s per-query bound-parameter limit for the full catalog.

## Validation

- API integration suite: eight scenarios covering catalog management, permissions, daily reports, removal/reinstatement, sign-in and refresh, stock reservation/cancellation, and a concurrent final-item checkout, and a full-size catalog exceeding 220 products.
- TypeScript and ESLint checks for the three websites; TypeScript for the API.
- OpenNext Cloudflare builds for all three websites.
- Local browser checks of responsive storefront, category filtering, customer sign-in, address entry, cash-on-delivery checkout, staff sign-in, and an employee report updated from ₹18,500 to ₹19,250 with the matching manager total and commission.
- Tests use ephemeral local D1, KV, and Durable Objects. No test employees, sales, customers, or orders are written to production.

## Visual asset provenance

The bathroom hero was generated with the OpenAI ImageGen tool in new-image mode. It is aspirational editorial artwork, not a supplier product photograph.

Saved production asset: `apps/web/public/images/brand/bathroom-editorial.webp`.

Prompt direction: Architectural editorial photography of a luxurious contemporary bathroom with ivory limewashed walls, travertine floor and backsplash, a floating walnut vanity, two white ceramic countertop basins, restrained chrome taps, a large softly rounded mirror, and a glass rain shower. Warm natural daylight, realistic materials, calm premium composition, no people, text, logos, or watermark. The final source was converted to a 1440-pixel WebP for the web.

The Matrizo mark is a code-native SVG in `apps/web/public/brandmark.svg`, with PNG app icons rendered from the same vector. Category illustrations already present in the project remain fallbacks; real product image URLs take priority.

## Operating notes

Employee reports represent daily totals, one per date, in India Standard Time. A later save replaces that day's total. Removed employees retain historical sales and can be restored. Commission estimates use the current rate, so a rate change affects historical estimates; no payroll settlement is implied.

Cash on delivery is available. SMS, online payments, password recovery, supplier imagery, and merchandising of currently empty categories remain operational follow-up work as described in the README.
